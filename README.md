 <h1> Авто Заявки </h1>

Генератор писем на завод. Вводите тип вагонов, номера и даты, а получаете готовое письмо в Word и PDF с шапкой, печатью и подписью.

Умеет делать два вида писем:

1. **Согласование погрузки:** месяц, декада, количество прописью, номера, маршруты.
2. **ГУ-12 на порожние вагоны:** количество, номера, график подачи, дата письма.

Номера вагонов проверяются автоматически: в номере 8 цифр, и последняя цифра должна быть контрольной. Опечатка в номере не попадёт в письмо.
